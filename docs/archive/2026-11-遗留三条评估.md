## 三、方法学教训（仍有效）

- 同源性前置闸：跑前跑后各跑 `_fingerprint.py`，三行 sha1 必须一致（2026-10-27 教训：跑批中途改 `SKILL.md`，12 run 仅 5 run 可靠）。
